# Mini Olimpíada de Robótica

Projeto desenvolvido para participação na Mini Olimpíada de Robótica do IFPB utilizando a plataforma LEGO Spike Prime.

O objetivo foi projetar, montar e programar robôs capazes de executar os desafios propostos pela competição, aplicando conceitos de programação, lógica, robótica e resolução de problemas.

## Tecnologias Utilizadas

- LEGO Spike Prime
- Programação em blocos de palavras (Spike Prime)
- Sensores de Cor
- Motores LEGO

## Componentes Utilizados

- Hub LEGO Spike Prime
- Motores LEGO Spike Prime
- Sensor de Cor
- Estruturas LEGO Technic

## Funcionamento

Os robôs foram programados para realizar as tarefas propostas pela Mini Olimpíada de Robótica, utilizando sensores para interpretar o ambiente e executar ações de forma autônoma.

## Aprendizados

Durante o desenvolvimento deste projeto foram aplicados conhecimentos de:

- Programação
- Lógica computacional
- Robótica educacional
- Montagem mecânica
- Uso de sensores
- Resolução de problemas
- Trabalho em equipe
